## Using These Files

1. Browse the repository and download the `.gpx` file for the route you want.
2. Import it into your preferred navigation app or transfer it to your GPS device.
3. Always preview a route before riding it. Conditions, road surfaces, and closures change.

> **Note:** These routes reflect conditions at the time they were recorded. Verify current road status before heading out, especially for remote or seasonal routes.

## Compatible Apps & Devices

### Web Viewer

If you want to preview a route without downloading an app, [gpx.studio](https://gpx.studio) is an excellent free web-based GPX viewer and editor. It renders routes on an interactive map, displays elevation profiles, and supports editing — all from your browser with no account required. If you find it useful, consider donating to the [site owner](https://github.com/gpxstudio) to help keep it free and maintained for the community.

### Mobile & Device Apps

The `.gpx` format is widely supported. The following apps are recommended across motorcycle, hiking, and overlanding use cases:

| App | Best For | Platforms |
|-----|----------|-----------|
| [OsmAnd Maps](https://osmand.net) | All-around navigation, offline maps | Android, iOS |
| [Gaia GPS](https://www.gaiagps.com) | Hiking, overlanding, backcountry | Android, iOS |
| [onX Offroad](https://www.onxmaps.com/offroad) | Overlanding, off-road, land ownership data | Android, iOS |
| [Komoot](https://www.komoot.com) | Motorcycle, hiking, cycling | Android, iOS, Web |
| [Scenic](https://scenicapp.space) | Motorcycle touring | iOS |

## Contributing

This repository is maintained by a single contributor. Direct push access is not open to the public, but community participation is welcome in the following ways:

**Report an error or suggest a correction**
Open a pull request with your proposed change. Please include a brief description of what was wrong and how your version improves it.

**Use these routes as a starting point**
You are welcome to fork this repository and adapt any routes for your own purposes.

If you have questions about a specific route, open an issue and I will do my best to respond.
